A ideia

Transformar dados cotidianos de smartwatches em uma infraestrutura de cuidado, ciência e prevenção.

O Sabiá Vitalis nasce como uma camada aplicada do Sabiá Data Lake para conectar dispositivos vestíveis, pessoas, pesquisadores e instituições. A proposta é criar um caminho responsável para coletar dados com permissão, organizar sinais de rotina e apoiar iniciativas em saúde conectada, acompanhamento remoto, envelhecimento saudável, estudos populacionais e inovação pública.

O sistema não substitui atendimento médico, diagnóstico ou serviços de urgência. Ele atua como uma plataforma de apoio: organiza dados, identifica padrões, reduz perdas de coleta e fortalece decisões baseadas em evidências.

Como funciona

Do cadastro à conexão com a plataforma.

O participante não entrega dados diretamente no formulário. Primeiro ele se cadastra. Depois, a equipe envia um link de conexão para que a autorização aconteça dentro do fluxo seguro da plataforma.

01

Pré-cadastro

O usuário informa nome, e-mail, WhatsApp, cidade, perfil e qual smartwatch ou aplicativo utiliza.

02

Envio do link

A equipe confirma elegibilidade e envia um link individual para conexão com a plataforma Sabiá Vitalis.

03

Consentimento

O participante autoriza os dados permitidos, com finalidade clara, registro de consentimento e possibilidade de revogação.

04

Sincronização

Os dados autorizados são organizados para análise, alertas operacionais, relatórios e pesquisa aplicada.

Confiança, ética e LGPD

Dados sensíveis exigem responsabilidade real.

O Sabiá Vitalis foi desenhado para uma experiência de coleta com consentimento, transparência, rastreabilidade e limitação de finalidade. A segurança não é um detalhe visual: é parte central da arquitetura.

Consentimento e finalidade

O participante entende por que os dados serão coletados, quais dados serão usados e como poderá revogar a autorização conforme o protocolo do projeto.

Controle de acesso

A visualização deve ser limitada por perfil, equipe, finalidade e necessidade operacional, com logs e auditoria.

Governança de dados

Os dados devem ser padronizados, protegidos, documentados e integrados ao Data Lake com rastreabilidade de origem.

Pré-cadastro

Entre na lista de conexão.

Preencha seus dados. A equipe do projeto enviará o link individual para conectar sua conta/dispositivo à plataforma com permissão explícita.

Importante

Este formulário não coleta dados de saúde. Ele registra apenas interesse e informações de contato para que a equipe envie o link correto de conexão.

  • Você decide se autoriza ou não a conexão.
  • A autorização acontece em ambiente próprio da plataforma/provedor.
  • O projeto deve seguir termo de consentimento, LGPD e protocolo institucional.

Para produção, configure no JavaScript o endereço do seu backend em CONFIG.registrationEndpoint. Sem endpoint, os dados ficam salvos apenas localmente no navegador como demonstração.
